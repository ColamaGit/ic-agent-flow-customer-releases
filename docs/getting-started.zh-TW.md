# 快速開始

[EN](./getting-started.md) | [zh-TW](./getting-started.zh-TW.md)

1. 在 `RELEASE_INDEX.zh-TW.md` 中找到現行生效的 bundle。
2. 選擇套件類型（`solo_eval` / `team_project` / `enterprise_site`）。
3. 閱讀套件類型的 `README.md` 與 `deployment/docs/*`。
4. 執行 `scripts/verify_release_bundle.sh <bundle_id>`。
5. 完成解壓縮/安裝/預飛測試/冒煙測試。
